# competitive-positioning-report

> 面向销售 / 产品 / 市场团队的「竞争及定位分析报告」生成 Skill：把我方产品与 2-3 个竞品对比，产出一份苹果官网风格的单文件 HTML 报告。

## 它产出什么

一份可直接在浏览器打开的单文件 HTML 报告，固定包含两个专属模块：

1. **核心差异化卖点**：每条卖点附「证据行 + 竞品对照行」，不打无依据的嘴仗。
2. **目标客户与目标场景**：由卖点反推 5 类优势客户、8 个场景适配度矩阵，外加「何时主动让给竞品」的诚实框。

章节骨架（7 章）：一页速览 → 产品概览 → 规格总对比表 → 关键指标图表 → 差异化卖点 → 目标客户与场景 → 结论与销售建议 → 数据来源与免责。

## 三条最高原则

- **数据保真**：官方未公布的指标一律填「—」，不推测、不换算补全，每个数字可回溯到来源清单。
- **对比但不打压**：写「竞品优势 / 我方对位优势」，禁用贬损与对垒措辞——客户拿同一问题问竞品，结论依然成立。
- **我方视角**：KPI、高亮列、图表配色都服务「我们是谁、赢谁、让谁」的主叙事，不是参数大杂烩。

## 适用场景

- 新产品上市前的竞品摸底
- 销售/售前应对具体竞品对比的话术底稿
- 内部产品定位评审材料

不适用：舆情分析、无明确竞品清单的市场研究、PPT/Word 交付。

## 视觉与工程特点

苹果官网风格：#F5F5F7 灰白交替章节、#0071E3 品牌蓝、毛玻璃吸顶导航（滚动联动高亮）、系统字体栈、跟随系统的深色模式、打印时图表自动降级为数据文字、窄屏表格滚动提示、WCAG AA 对比度。
