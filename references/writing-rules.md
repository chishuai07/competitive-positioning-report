# 文案语气规范：对比但不打压

## 总原则

读者是内部销售/产品。报告的价值在于**可信**，不是在于「我们赢」。打压竞品的文案会被客户一句话拆穿，反过来伤害我方可信度。每一处对比都要做到：客户拿同一问题去问竞品，结论依然成立。

## 禁用 → 改写对照

| 禁用（对垒/贬损） | 改为（事实对位） |
| --- | --- |
| 他的刀 / 我们的盾与矛 | 竞品优势 / 我方对位优势 |
| 对阵 / 正面开战 / 胜负手 / 最锋利的一把刀 | 对比 / 做正面对比 / 我方优势 |
| 他给不出的数字 / 停留在模型树脂 | 官方未公布该口径 / 竞品官方材料线以模型树脂为主 |
| 代差 / 独占位 | 差异化位置 |
| 让你睡踏实 / 页面这一栏是空的 | 可无人值守运行 / 该指标官方未公布 |

## 一句话结论（05 章客户行、06 章结论）

- 每条 ≤35 字，结论前置。
- 句式：双方各留余地 + 选型依据。示例：「竞品胜在幅面，我们胜在整板良率与无人值守，按夜印成本选型即可。」
- 禁感叹号、禁「碾压/秒杀/吊打」类词。

## 竞品强项怎么写

- 在 00 速览 caption、06 结论开头主动列出（幅面、价格、像素精细度等），用「竞品优势：……」句式，不评价好坏，只陈述事实。
- 价格差要翻译成决策语言：「37% 的价差主要落在自动化与生产保障能力上，建议按总拥有成本评估」，而不是「便宜没好货」。

## 诚实让位（05 章必备框）

明确写出什么单子该让：
- 例：「以模型创作为主、单件大幅面模型创作为主的团队，在竞品处同样能获得好体验。」
- 这一段让销售在客户面前立住「不是什么都卖」的专业人设，反而提高成单率。

## 证据行

卖点卡上每个我方标称数字都要带出处（来源编号或「官方标称」），并在 07 章可回溯。无官方依据的自研话术不要进卖点卡。
